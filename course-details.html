Data Structures

Seats: 24 / 30 Available 3 Credit Hours
ACADEMIC CONTENT

Course Syllabus & Topics

This course explores advanced linear and non-linear data structures, focusing on their memory representation, algorithm implementation efficiency, and practical application in software engineering.

Weekly Outline

  • Weeks 1–3: Asymptotic notation (Big-O), Recursion analysis, and Advanced Sorting algorithms.
  • Weeks 4–6: Singly & Doubly Linked Lists, Stacks, Queues, and Applications in Expression Evaluation.
  • Weeks 7–9: Binary Trees, Binary Search Trees (BST), AVL Self-Balancing Trees, and Tree Traversals.
  • Weeks 10–12: Priority Queues, Binary Heaps, Hash Tables, and Collision Resolution Techniques.
  • Weeks 13–15: Graph Representations (Adjacency Matrix/List), BFS, DFS, Dijkstra’s Shortest Path, and Final Project.
